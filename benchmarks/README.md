# Benchmarks

Keris is compared against Python using the same algorithms. Run from the project root:

```bash
python run_benchmarks.py
```

- **Scripts**: `bench_fibonacci.ks`, `bench_factorial.ks`, `bench_loop.ks` — runnable Keris programs.
- **Report**: `report.html` — comparison chart and times (generated by the runner).

Python is the baseline (1×). Keris is interpreted by Python, so it is expected to be slower.
